# Falling Sand Simulator

Very basic falling sand simulation. Still in development.

Compile with `g++ main.cpp player.cpp -o sand.exe -lraylib`

Run: `./sand.exe`

## Key Binds

| Key           | Action                 |
| ------------- | ----------------------|
| **1**         | Select Sand           |
| **2**         | Select Water          |
| **3**         | Select Stone          |
| **4**         | Select Lava           |
| **5**         | Select Steam          |
| **Left Click**  | Apply Material        |
| **Right Click** | Remove Material       |
| **- / +**     | Change Brush Size     |
| **A / D**     | Move Left/Right       |
| **Space / W** | Jump                  |

More documentation and examples coming soon.
